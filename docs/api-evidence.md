验证日期：2026-10-11；来源：[music.lzmhhh.com](https://music.lzmhhh.com/)。

| 功能 | 方法与路径 | 关键参数 | 结果 |

音频地址支持 HTTP Range，因此 Go 暴露 `/media?url=...` 转发给 WebView；页面不接触账号令牌，账号令牌只由 Go 保存在应用私有目录。

扫码注册的验证码由 Go 请求并绑定到当前注册会话，手机通过同源 `/phone/<session>/captcha-image?v=<version>` 加载 SVG。刷新会使旧图片版本失效；取消、过期、其它 scope 均不可访问。手机页显示加载和失败状态，图片加载成功后才允许提交，失败可点击“换一张”重试。
