# 明明音乐 TV v0.1.1

- 启动页增加应用 Logo 与环绕旋转的圆形进度环，显示「正在启动明明音乐...」和版本号；服务或页面加载失败时可重试。
- 退出应用后恢复上次歌曲、进度、播放列表及播放顺序，保持暂停。按播放后重新获取音源并从保存的位置继续。
- 播放记录保存在设备本机，支持服务端口变化；登录、退出账号及收藏同步不会清除播放进度。

包名与签名保持一致，可覆盖安装 v0.1.0。支持 Android 6.0 及以上，包含 arm64-v8a、armeabi-v7a、x86_64。

浏览器验证涵盖跨端口重启、暂停恢复、续播定位和焦点回归；Android 构建与 lint 在 CI 执行。启动页外观和实际音频兼容性仍需电视实机确认。
