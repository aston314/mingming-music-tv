# 明明音乐 TV v0.1.5

- 底部控制栏的播放列表入口打开与全屏播放相同的右侧弹窗，显示当前播放来源及数量；关闭或返回后恢复入口焦点。
- 全屏歌名下方和播放列表行补全「歌手 · 专辑」信息，修复歌曲信息被布局挤掉的问题。
- 正在播放的 SVG 音柱随实际播放状态动画，暂停、缓冲或失败时停止。
- 播放列表行在收藏前增加添加/删除队列图标，状态随操作同步；自定义播放列表支持直接删除。
- 修复手机扫码登录时下线其它设备失败的处理：用户名与邮箱按实际身份提交，下线后自动重新登录，设备列表变化或临时失败可继续选择和重试。
- 保留当前全屏高亮歌词的字号调整。

包名、签名及 Android 版本支持保持不变，可覆盖安装 v0.1.4 并保留应用数据。支持 Android 6.0 及以上，包含 arm64-v8a、armeabi-v7a、x86_64；只发布签名 Release APK。

Go race/vet、ES5 兼容检查、项目合同和浏览器回归已通过；播放器在 1920×1080、960×540 及手机登录在 390×844 的隔离测试通过。Android 单元测试、Lint、三 ABI 打包和签名由 GitHub Actions 完成。实体 TV 播放及真实手机账号下线登录仍需安装后验证。
