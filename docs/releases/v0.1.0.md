# 明明音乐 TV v0.1.0

首个 Android TV 测试版本，包名 `com.aston.mingmingmusic`，支持 Android 6.0 及以上，包含 arm64-v8a、armeabi-v7a、x86_64 三种架构。

- 歌单与分类筛选、排行榜、多来源歌曲搜索、搜索历史及手机扫码搜索。
- 歌曲列表播放、收藏与播放队列管理，队列添加/删除图标随状态切换。
- 全屏与侧栏同步歌词；全屏歌词和评论标题采用统一的绿色圆角标签。
- 评论头像、分页、播放时缓慢上移与暂停时停止。
- 账号登录、注册、找回密码及手机扫码输入。
- 启动默认焦点及遥控器四方向导航。

已完成浏览器与 fixture 验证；此版本供电视实机测试，不将浏览器播放结果视为实体电视兼容证明。上游音乐服务和曲源可用性取决于原站。当前通过私有 GitHub Release 或本地 APK 安装，尚未启用应用内升级。
