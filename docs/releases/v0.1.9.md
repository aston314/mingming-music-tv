# 明明音乐 TV v0.1.9

- 修复全屏播放收起评论时，切换下一首后评论数一直显示 0 的问题。新歌曲仍请求评论第一页以获取总数，加载中显示“…”；返回结果后自动刷新收起按钮上的评论数。
- 收起状态不加载后续分页，展开时复用已取得的第一页并继续正常分页。快速切歌时隔离上一首的迟到响应，评论数刷新保持开关焦点和收起状态。

沿用 v0.1.8 的逐字/四行歌词、艺人和专辑详情以及封面缩图优化。包名、签名、Android 6.0 最低版本和三个 ABI 保持不变，可覆盖安装旧版并保留应用数据。只发布签名 Release APK。

两种电视视口的浏览器回归覆盖收起切歌、加载提示、零评论、快速切歌迟到响应、隐藏分页和展开复用；发布流程继续检查 Android 单元测试、Lint、三 ABI 和签名，实体电视表现需设备验证。
