# 明明音乐 TV v0.1.8

- 新增歌曲的艺人信息入口，可查看歌手热门歌曲、懒加载专辑和专辑歌曲；播放热门、播放专辑使用统一的 SVG 播放按钮。遥控返回逐层恢复详情、弹窗和原列表焦点，Android 端隐藏页面返回按钮。
- 接入真实逐字歌词时间数据，完整歌词列表自动跟随当前句，从左到右逐字高亮；无逐字数据时回退普通歌词。普通模式当前句适度放大，歌词不参与遥控焦点。
- 全屏隐藏评论时切换为四行大字歌词，显示上一句、当前句和下两句；长句按可用空间缩小，暂停或缓冲时停止动画，拖动进度直接定位。展开评论后恢复完整歌词列表。
- 全屏顶部以“歌手 · 专辑”替代“正在播放”，长文字单行省略；歌词加载区合并为一个圆环提示，服务连接状态移至应用名称角标。
- 全屏网易云封面使用 400×400 请求，避免重复设置相同图片地址，并仅在显示且播放时启用旋转合成提示，减少图片加载与旋转开销。

包名、签名、Android 6.0 最低版本和三个 ABI 保持不变，可覆盖安装旧版并保留应用数据。只发布签名 Release APK。

发布流程检查 Go race/vet、ES5、TV 项目合同、浏览器回归、Android 单元测试、Lint、三 ABI 内嵌资源与 APK 签名；Shield TV 和 Android 6 实际播放表现仍需设备验证。
