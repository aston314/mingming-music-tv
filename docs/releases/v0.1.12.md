# 明明音乐 TV v0.1.12

- 修复 Android 6 和低配置 WebView 上歌词滚动抖动、逐字节拍与 CSS 高亮不同步的问题。
- 页面歌词使用补偿时钟跟随原生播放进度，逐字高亮只更新当前句并限制样式刷新频率，避免旧 WebView 每帧遍历和重复布局。
- 普通歌词行保持固定高度，当前句放大不再挤动后续内容；歌词滚动增加安全区域，四行歌词兼容旧 WebView 的过渡和变换属性。
- 播放暂停、缓冲、拖动、切歌和后台切换时正确冻结歌词动画；准备和缓冲期间保持封面旋转，减少控制区闪动。

包名 `com.aston.mingmingmusic`、签名、Android 6.0 最低版本和三个 ABI 保持不变，可覆盖安装旧版并保留应用数据。本版只发布签名 Release APK，不发布 Debug APK。

项目合同、Go race/vet、Python 测试、ES5 检查、完整浏览器回归、Android 6 能力模拟和焦点性能回归已通过；实体 Android 6 设备仍需安装后确认实际歌词播放效果。
