# 明明音乐 TV v0.1.11

- 修复 Android 6 旧 WebView 下底部正在播放入口无法打开全屏播放器的问题，触摸、遥控确认键和键盘 Enter 使用同一入口，并保留返回后的焦点。
- 为全屏播放器增加旧 WebView 的四边定位和无 Grid 布局回退，避免播放器弹层显示在可视区域外。
- 修复旧 WebView 下逐字歌词高亮依赖 CSS 变量导致文字不可见的问题；支持固定颜色的逐字渐变，以及不支持文字裁剪时的逐词变色回退。
- 全屏控制栏补足焦点环留白，保持 Android TV 方向键导航可见。

包名 `com.aston.mingmingmusic`、签名、Android 6.0 最低版本和三个 ABI 保持不变，可覆盖安装旧版并保留应用数据。本版只发布签名 Release APK，不发布 Debug APK。

发布前通过项目合同、ES5、Go 服务测试、完整浏览器回归、播放恢复、评论/队列/焦点检查，以及关闭旧 CSS 能力的 Android 6 模拟检查；实体 Android 6 设备仍需安装后验证。
