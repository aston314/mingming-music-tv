# 明明音乐 TV v0.1.4

- 播放音频迁移到 Android 原生 Media3 前台播放服务，切换到后台后继续播放，并提供系统媒体控制；回到应用时同步播放状态、进度和歌词。
- 启动页 Logo 缩小，与外围圆形进度环保留间距；继续显示「正在启动明明音乐...」和版本号。
- 首页真正退出时显示「退出明明音乐？」确认框，默认焦点在“取消”；返回键取消并恢复原焦点，只有确认“退出”才暂停、保存播放进度并关闭应用。
- 补充原生播放队列循环、单曲循环、随机播放和暂停恢复的单元测试；焦点回归覆盖退出确认流程。

包名、签名、应用数据和支持的 Android 版本保持不变，可覆盖安装 v0.1.3。支持 Android 6.0 及以上，包含 arm64-v8a、armeabi-v7a、x86_64。

浏览器、Go race/vet 和项目合同检查已通过；Android Media3 编译、Lint、三 ABI 打包和签名由 GitHub Actions 完成。后台播放、媒体通知和退出清理仍需在实体 Android TV 上确认。
