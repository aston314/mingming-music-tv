# 明明音乐 TV v0.1.6

- 播放列表弹窗增加数据、封面请求的加载状态，异步刷新不会抢走当前焦点，失败后仍保留可操作列表。
- 恢复紧凑歌曲列表布局，歌曲副标题显示歌手，非全屏歌词保持非交互并继续自动高亮滚动。
- 全屏评论与歌词使用独立滚动区域；评论支持头像、瀑布式分页、自动滚动和暂停恢复。
- 全屏标题行最右侧增加评论显示开关。隐藏评论后歌词扩展占用空间，按钮保持焦点；隐藏状态按钮显示评论 SVG、评论文字和动态评论总数，展开后恢复隐藏图标与评论位置。
- 完善全屏评论开关在 1920×1080 和 960×540 下的布局、对齐和遥控器焦点路径。

包名、签名及 Android 版本支持保持不变，可覆盖安装 v0.1.5 并保留应用数据。支持 Android 6.0 及以上，包含 arm64-v8a、armeabi-v7a、x86_64；只发布签名 Release APK，不发布 Debug APK。

Go race/vet、ES5 兼容检查、项目合同、Android 单元测试、Lint、浏览器回归和三 ABI 签名构建由 GitHub Actions 完成。实体 TV 播放和真实账号操作仍需安装后验证。
