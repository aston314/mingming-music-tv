# 明明音乐 TV v0.1.10

- 调整 Android TV 浏览器画布为 1920×1080 基准，并按可用窗口等比例居中缩放，统一不同分辨率下的界面比例。
- 焦点定位、评论滚动和歌词定位同步按画布比例换算，避免整体缩放后方向键高亮与滚动区域位置不一致。

沿用 v0.1.9 的收起评论切歌后自动刷新评论数修复，以及已有的逐字/四行歌词、艺人与专辑详情和播放器功能。包名、签名、Android 6.0 最低版本和三个 ABI 保持不变，可覆盖安装旧版并保留应用数据。只发布签名 Release APK。

发布流程运行项目合同、Python 测试、Go race/vet、ES5 与浏览器回归、Android 单元测试、Lint、三 ABI 交叉编译及 Release 签名验证。不同 TV 分辨率布局在浏览器中检查；实体设备仍需验证实际遥控和播放表现。
