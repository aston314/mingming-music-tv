# 明明音乐 TV v0.1.7

- 修复 Shield TV 和 Android 系统媒体卡片的“打开”操作：使用明确的 Launcher 启动意图，支持恢复已有应用、重新获得 WebView 焦点并刷新播放状态。
- 播放器记录隐私安全的错误分类和 Media3 错误码；网络连接、超时、HTTP 状态和无效音频类型错误最多自动重新获取播放地址并重试一次，解码错误不无限重试。
- 播放失败时在歌词区域显示可读的网络、播放源、格式或地址错误提示，成功进入 READY 后自动清理旧错误状态。
- 保持在线播放策略：Go 媒体代理流式转发，播放器没有完整音频磁盘缓存，连续播放不会把歌曲文件持续写满设备存储。

包名、签名、Android 6.0 最低版本和三个 ABI 保持不变，可覆盖安装 v0.1.6 并保留应用数据。只发布签名 Release APK，不发布 Debug APK。

Go race/vet、ES5 兼容检查、项目合同和浏览器回归已通过；Android 单元测试、Lint、三 ABI 编译和实体 Shield TV 播放仍由发布流程/设备验证确认。
